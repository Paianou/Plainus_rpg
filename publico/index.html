Suas mesas

As campanhas moram no servidor da mesa (o computador de quem mestra). Baixe um backup de vez em quando (no menu do cartão do Mestre): o arquivo leva os segredos da campanha — guarde para você.

Campanhas da versão antiga

Ficaram guardadas neste navegador, de antes de a mesa rodar pelo servidor. Baixe o backup de cada uma e, com o servidor ligado, use “Restaurar backup” (lá embaixo) para trazê-las.

Tenho um convite

Campanhas novas são criadas no computador onde o servidor está rodando: lá, abra http://localhost:3000. Daqui, dá para entrar como Mestre numa mesa que já existe (logo abaixo).

Pelo link, criar campanha (ou restaurar backup) pede a senha que está no arquivo .env do servidor. Os jogadores não precisam dela.

A senha é a que você definiu ao criar a mesa (ou em "Editar campanha"). Sem senha, a mesa só abre no navegador onde foi criada.
